# 集計レポート

## 目的

`data/生まれ表一覧.xlsx` を一度だけ読み取り、ソードワールドの種族ごとの能力値傾向を確認しやすい JSON データにしました。

完成版 UI は作らず、今回は集計結果の確認を優先しています。

## 確認したシート

Excel には次の 3 シートがありました。

| シート名 | 確認結果 |
| --- | --- |
| 発表順 | 種族、各生まれ、能力値の元データが入っていました。今回の集計元として使用しました。 |
| 系統順 | `発表順` と同じ種類のデータが、別の順番で並んでいました。重複集計を避けるため今回は使用していません。 |
| 能力値合計一覧 | 種族ごとの合計値確認に使いました。 |

## 読み取り方

`発表順` シートでは、種族行と生まれ行が分かれていました。

種族行には、6つの能力値それぞれのダイス表記が入っています。

| 能力値 | Excel上の位置 |
| --- | --- |
| 器用 | 種族行の「器用」 |
| 敏捷 | 種族行の「敏捷」 |
| 筋力 | 種族行の「筋力」 |
| 生命力 | 種族行の「生命力」 |
| 知力 | 種族行の「知力」 |
| 精神力 | 種族行の「精神力」 |

生まれ行には、`技`、`体`、`心` の値が入っています。

能力値は次のように作りました。

| 能力値 | 計算 |
| --- | --- |
| 器用 | 種族の器用ダイス + 生まれの技 |
| 敏捷 | 種族の敏捷ダイス + 生まれの技 |
| 筋力 | 種族の筋力ダイス + 生まれの体 |
| 生命力 | 種族の生命力ダイス + 生まれの体 |
| 知力 | 種族の知力ダイス + 生まれの心 |
| 精神力 | 種族の精神力ダイス + 生まれの心 |

## ダイスの扱い

今回の指定どおり、ダイスは次の値に変換しました。

| 表記 | 最小値 | 平均値 | 最大値 |
| --- | ---: | ---: | ---: |
| 2d | 2 | 7 | 12 |
| 1d | 1 | 3.5 | 6 |

`2d+6`、`1d-3` のような表記は、ダイスを変換したあとに固定値を足し引きしています。

例: `2d+6`

| 種類 | 値 |
| --- | ---: |
| 最小値 | 8 |
| 平均値 | 13 |
| 最大値 | 18 |

## 種族ごとの集計

同じ種族に属するすべての「生まれ」を同じ重みで平均しました。

例として、ある種族に 10 個の生まれがある場合、10 個すべてを同じ 1 件として扱っています。

## 出力した JSON

出力先:

```text
data/race-stats.json
```

主な構造:

```text
metadata
races[]
  raceName
  source
  birthCount
  baseExpressions
  stats
    min
    avg
    max
  births[]
```

`stats.min`、`stats.avg`、`stats.max` の中に、6能力値の集計結果が入っています。

後でレーダーチャートを作るときは、まず `races[].stats.avg` を使うと扱いやすいです。

## 判断に迷った点

### 派生種の扱い

`タビット（パイカ種）`、`タビット（リパス種）`、`ウィークリング（タンノズ）` など、同じ番号の近くに派生種が並ぶ箇所がありました。

これらは種族ダイスが異なるため、今回は別々の種族として集計しました。

理由は、レーダーチャートでは能力値傾向が変わるものを別データとして選べたほうが確認しやすいためです。

### 初期技能が空の生まれ

`化け猫` の `侍`、`忍者`、`呪術師`、`巫覡` は、初期技能の列が空でした。

ただし `技`、`体`、`心` の値は入っていたため、生まれ行として扱いました。

### 生まれ側のダイス

`人間` の `冒険者` のように、生まれ側の `技`、`体`、`心` に `2d` が入っている行がありました。

この場合も、指定されたダイスルールで最小値・平均値・最大値に変換してから、種族ダイスに加算しました。

### 合計一覧との不一致

`能力値合計一覧` シートと照合したところ、多くの種族は平均値の合計が一致しました。

ただし、次の 2 件は詳細表から計算した合計と、合計一覧の値が一致しませんでした。

| 種族 | 合計一覧の値 | 詳細表から計算した平均合計 | 差 |
| --- | ---: | ---: | ---: |
| アルヴ | 87 | 90 | +3 |
| ケンタウロス | 86 | 93 | +7 |

今回はレーダーチャート用に6能力値それぞれの値が必要なため、`発表順` シートの詳細な6能力値を優先して JSON を作りました。

この不一致は `data/race-stats.json` の `metadata.validationWarnings` にも入れています。

## 作成した確認画面

次のファイルで、集計結果を表として確認できます。

```text
index.html
style.css
script.js
data/race-stats.js
```

`data/race-stats.json` は集計結果の元データとして残しています。

`data/race-stats.js` は、`index.html` を直接開いてもブラウザが読み込める表示用データです。

画面では、種族名、出典、生まれ数、最小・平均・最大の6能力値を一覧表示します。

種族名で簡単に絞り込みもできます。

## 確認方法

### 方法1: index.html を直接開く

一番簡単な確認方法です。

1. `index.html` をダブルクリックします。
2. ブラウザで「種族ステータス集計」画面が開きます。
3. 表に種族ごとの数値が表示されていれば成功です。

この方法では、`data/race-stats.js` を画面が直接読み込みます。

### 方法2: ローカルサーバーで開く

コマンド操作に慣れている場合は、次の方法でも確認できます。

1. プロジェクトフォルダを開きます。
2. 次のコマンドを実行します。

```powershell
python -m http.server 4173
```

3. ブラウザで次のURLを開きます。

```text
http://127.0.0.1:4173/
```

どちらの方法でも、同じ表が表示されます。

もし「集計データ data/race-stats.js が読み込まれていません」と表示された場合は、`index.html` で `data/race-stats.js` が `script.js` より先に読み込まれているか確認してください。

## レーダーチャートの確認方法

`index.html` を開くと、画面上部にレーダーチャートが表示されます。

1. 「チャート表示する種族」で `人間` を選びます。
2. `最小`、`平均`、`最大` の3本線が表示されることを確認します。
3. 種族を `エルフ` などに変更します。
4. チャートと右側の種族情報が切り替われば成功です。

チャートの近くには、現在使っているダイス設定も表示しています。

```text
1d = 最小1 / 平均3.5 / 最大6
2d = 最小2 / 平均7 / 最大12
```

## ダイス設定を変更する場所

ダイス設定は `scripts/aggregate_race_stats.py` の `DICE_CONFIG` にまとめています。

現在は正式値のままです。

```python
DICE_CONFIG = {
    "1d": {"min": 1.0, "avg": 3.5, "max": 6.0},
    "2d": {"min": 2.0, "avg": 7.0, "max": 12.0},
}
```

将来、グラフ表示用に範囲を狭めたい場合は、ここだけを変更して再集計します。

例:

```python
DICE_CONFIG = {
    "1d": {"min": 2.0, "avg": 3.5, "max": 5.0},
    "2d": {"min": 5.0, "avg": 7.0, "max": 9.0},
}
```

変更後は、次のコマンドで `data/race-stats.json` と `data/race-stats.js` を作り直します。

```powershell
python scripts/aggregate_race_stats.py
```

このダイス設定は、出力データの `meta.diceConfig` にも保存されます。
