# ソードワールド 種族ステータス可視化

このページは、ソードワールドの種族ごとの能力値傾向を確認するための可視化ツールです。

集計済みデータを使って、種族ごとの最小値・平均値・最大値をレーダーチャートと表で表示します。

## できること

- 種族を1つ選んでレーダーチャートを表示できます。
- 種族を切り替えると、チャートも切り替わります。
- 最小・平均・最大の3本線を重ねて確認できます。
- 画面下の表で、全種族の集計値を一覧確認できます。

## 使い方

1. ページを開きます。
2. 「チャート表示する種族」から見たい種族を選びます。
3. レーダーチャートで能力値の傾向を確認します。
4. 詳しい数値を見たい場合は、下の表を確認します。

## グラフの見方

レーダーチャートの軸は、次の6つです。

- 器用
- 敏捷
- 筋力
- 生命力
- 知力
- 精神力

グラフには3本の線があります。

| 線 | 意味 |
| --- | --- |
| 最小 | その種族の各生まれを集計したときの最小寄りの値 |
| 平均 | その種族の各生まれを集計したときの平均的な値 |
| 最大 | その種族の各生まれを集計したときの最大寄りの値 |

各種族にある複数の「生まれ」は、同じ重みで平均しています。

## 現在のダイス設定

現在は、正式なダイス期待値に基づいて集計しています。

| ダイス | 最小 | 平均 | 最大 |
| --- | ---: | ---: | ---: |
| 1d | 1 | 3.5 | 6 |
| 2d | 2 | 7 | 12 |

画面上にも、現在使っているダイス設定を表示しています。

## 注意事項

- このツールは、今回用意した集計済みデータを表示するための静的ページです。
- ブラウザ上でExcelファイルを読み込む機能はありません。
- 元のExcelファイルや集計用Pythonスクリプトは、この公開用フォルダには含めていません。
- レーダーチャートの目盛り最大値は、種族間で比較しやすいように35で固定しています。
- このページは、ゲーム内容の理解や比較を助けるための確認用ツールです。
