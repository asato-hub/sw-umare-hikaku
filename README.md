# ソードワールド種族ステータス可視化

## 概要

このプロジェクトは、ゲーム「ソードワールド」の種族ごとの能力値傾向を、レーダーチャートで視覚的に確認するためのものです。

目的は、汎用的なWebアプリを作ることではなく、今回用意したExcelデータから一度だけ集計・可視化結果を作ることです。

Excelデータは今後変化しない前提です。

## 入力データ

元データは以下のExcelファイルです。

```text
data/生まれ表一覧.xlsx
```

このExcelには、ソードワールドにおける各種族の「生まれ」ごとの能力値データが含まれています。

主に扱う能力値は以下の6つです。

* 器用
* 敏捷
* 筋力
* 生命力
* 知力
* 精神力

## データの考え方

ソードワールドでは、キャラクター作成時に「種族」と「生まれ」を選び、その後にダイスを振って能力値を決定します。

そのため、各能力値には以下の要素があります。

* 生まれによる固定値
* `2d` などのダイスによるランダム値

このプロジェクトでは、ダイスによるばらつきを視覚的に確認できるように、能力値を以下の3種類で集計します。

* 最小値
* 平均値
* 最大値

## ダイスの扱い

最初は、以下のルールでダイスを数値化します。

### 2d

* 最小値: 2
* 平均値: 7
* 最大値: 12

### 1d

* 最小値: 1
* 平均値: 3.5
* 最大値: 6

例：

```text
5 + 2d
```

という能力値の場合、以下のように扱います。

```text
最小値 = 5 + 2 = 7
平均値 = 5 + 7 = 12
最大値 = 5 + 12 = 17
```

## 種族ごとの集計方針

各種族には複数の「生まれ」があります。

このプロジェクトでは、種族全体の傾向を見るために、同じ種族に属するすべての「生まれ」を同じ重みで平均します。

つまり、以下のように集計します。

```text
種族の最小値 = その種族に属する各生まれの最小値の平均
種族の平均値 = その種族に属する各生まれの平均値の平均
種族の最大値 = その種族に属する各生まれの最大値の平均
```

特定の生まれがよく選ばれる、あまり選ばれない、という重みづけは行いません。

## 目標とする表示

添付画像のようなレーダーチャート風のUIを目標にします。

1つの種族について、以下の3本の線を重ねて表示します。

* 最小値ライン
* 平均値ライン
* 最大値ライン

これにより、以下のようなことを視覚的に確認できるようにします。

* どの種族はどの能力が高いか
* どの能力に偏りがあるか
* ダイスによるばらつきが大きい種族か
* 最大値と最小値の差が大きい種族か

例：

人間の最大値ラインと最小値ラインの差が大きい場合、
「人間は能力値のばらつきが大きい種族」と視覚的に分かるようにします。

## 開発方針

このプロジェクトは、汎用的なアプリではなく、今回限りの出力を得ることを目的とします。

そのため、ブラウザ上でExcelを毎回読み込む機能は優先しません。

基本方針は以下です。

```text
Excelを一度だけ解析する
↓
種族ごとの集計済みデータを作る
↓
集計結果を確認する
↓
集計済みデータを使ってレーダーチャートを表示する
```

## 最初の目標

最初から完成版UIを作らず、まずは以下を行います。

1. Excelファイルを読み取る
2. シート構造を確認する
3. 種族、生まれ、能力値を抽出する
4. `2d` や `1d` を最小・平均・最大に変換する
5. 種族ごとの集計済みデータを作成する
6. 集計結果を表で確認できるようにする
7. アプリ側で使いやすいJSONデータを出力する

## 想定する成果物

最初の段階では、以下のような成果物を目指します。

```text
data/race-stats.json
```

種族ごとの集計済みデータ。

```text
docs/aggregation-report.md
```

集計ルール、読み取り結果、判断に迷った点などの説明。

```text
index.html
style.css
script.js
```

集計済みデータを使って、表またはレーダーチャートを表示するための最小構成。

## 注意事項

* いきなり完成版UIを作らない
* Excelの読み取りと集計結果の確認を優先する
* 集計ルールが曖昧な箇所は勝手に断定しない
* 表の読み取りで判断に迷った箇所は報告する
* 初心者でも確認できるように、変更内容と確認方法を説明する
